# 1. p5.js 슬라이더로 Arduino LED 밝기 조절하기

## 2. 동작 원리

p5.js로 만든 웹 화면에서 슬라이더를 움직이면 밝기 값이 USB 시리얼 통신을 통해 아두이노로 전달된다. 슬라이더 값의 범위는 0~255이며, 0은 LED가 꺼진 상태이고 255는 최대 밝기이다.

아두이노는 받은 값에 따라 LED가 켜져 있는 시간의 비율을 조절한다. LED를 빠르게 켜고 끄면 사람이 보기에는 밝기가 변하는 것처럼 보인다. 이러한 방식을 PWM이라고 한다.

이번 회로의 LED는 D13에 연결되어 있다. Arduino Uno R3의 D13은 일반 PWM 핀이 아니므로, Timer1을 이용한 소프트웨어 PWM으로 밝기를 조절하도록 작성하였다.

LCD에는 LED 밝기와 가변저항 값이 표시된다. 버튼은 LED를 끄는 용도로 사용하며, 가변저항은 값을 표시하는 데 사용한다. 가변저항이 LED 밝기를 직접 조절하지는 않는다.

## 3. 코드 설명

### ① 화면과 슬라이더 생성

setup()에서 화면과 아두이노 연결 버튼을 만든다.
createSlider()로 0~255 범위의 슬라이더를 생성하며, 초기값은 0으로 설정한다.

draw()에서는 슬라이더 값, LED 밝기 미리보기, 아두이노의 응답 값을 화면에 표시한다.

### ② 슬라이더 값 전송

슬라이더를 움직이면 sendBrightness()가 현재 값을 읽어 아두이노로 전송한다.

드래그 중에는 약 40ms 간격으로 최신 값을 보내 불필요한 통신을 줄인다.

### ③ 시리얼 통신

serial-helper.js는 USB 포트 연결과 데이터 송수신을 담당한다.

통신 속도는 9600 baud이며, 전송하는 값 끝에 줄바꿈을 붙여 데이터의 끝을 구분한다.

아두이노에서 보내는 LED 밝기와 가변저항 값도 줄 단위로 받아 화면에 반영한다.

### ④ LED 밝기 제어

아두이노는 받은 값이 0~255 범위의 정수인지 확인한 뒤 밝기 변수에 저장한다.

Timer1 인터럽트에서는 이 값을 기준으로 D13의 켜짐과 꺼짐을 반복한다. 값이 클수록 LED가 켜져 있는 시간이 길어져 더 밝게 보인다.

### ⑤ LCD·버튼·가변저항 처리

LCD 첫째 줄에는 LED 밝기를, 둘째 줄에는 가변저항 값과 버튼 상태를 표시한다.

D2 버튼을 누르면 LED가 꺼지고 웹 슬라이더도 0으로 돌아간다.

가변저항은 A0에서 값을 읽으며, LCD 표시와 가변저항 값 전송은 200ms마다 갱신한다.

### ⑥ 코드 파일 구성

- p5/sketch.js: 슬라이더와 화면 표시
- p5/serial-helper.js: 아두이노 연결과 시리얼 통신
- p5/index.html: p5.js와 JavaScript 파일을 불러오는 웹 화면
- led_pwm_slider/led_pwm_slider.ino: 아두이노의 LED·LCD·버튼·가변저항 제어

아두이노 코드는 Uno R3 전용이며, LCD 사용에는 LiquidCrystal I2C 라이브러리가 필요하다.

## 4. 고찰

이 프로젝트의 핵심은 웹 화면에서 입력한 값을 실제 하드웨어 제어에 연결하는 것이다. 단순히 LED를 켜고 끄는 것과 달리, 밝기를 조절하려면 PWM과 핀의 기능을 함께 고려해야 한다.

특히 D13은 일반 PWM 핀이 아니므로 배선을 유지하려면 타이머를 이용한 별도 처리가 필요하다. 처음부터 PWM 지원 핀을 사용하면 코드를 더 간단하게 구성할 수 있다.

또한 화면의 LED 미리보기가 변하는 것만으로 실제 LED가 정상 동작한다고 판단할 수는 없다. 통신 연결 상태와 아두이노의 응답을 확인하고, 실제 LED의 밝기도 직접 비교해야 한다.

앞으로 밝기 단계별 동작과 버튼·LCD 연동을 실제 보드에서 확인하고, 결과 사진을 추가할 필요가 있다.
