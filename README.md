# p5.js 슬라이더를 이용한 LED 밝기 조절

## 1. 프로젝트 소개
웹 화면의 슬라이더를 움직여 아두이노에 연결된 LED의
밝기를 조절하는 프로젝트입니다.

## 2. 준비물
- Arduino Uno R3
- LED
- LED 전류 제한용 저항
- 브레드보드
- 점퍼선
- USB 케이블

## 3. 동작 원리
1. p5.js에서 슬라이더 값을 읽는다.
2. 시리얼 통신으로 값을 아두이노에 전달한다.
3. 아두이노가 PWM으로 LED의 밝기를 조절한다.

## 4. 회로 연결
실제 사용한 핀 번호와 회로 사진을 추가한다.

## 5. 소스 코드
아두이노 코드와 p5.js 코드를 추가한다.
